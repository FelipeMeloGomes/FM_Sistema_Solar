# FM Sistema Solar

Um sistema solar animado feito em HTML, CSS e JavaScript, com planetas em órbita.

## Sobre

Animação do sistema solar com planetas orbitando o sol, construída com CSS para os movimentos e JavaScript para controle da cena.

## Funcionalidades

- Planetas em órbita ao redor do sol
- Animações em CSS
- Visualização estelar

## Como executar

Abra o arquivo `index.html` em qualquer navegador.

## Deploy

[Sistema Solar — demonstração](https://sytem-sun.netlify.app/)

- CSS
